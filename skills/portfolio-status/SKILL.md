# Portfolio status

1. Start with `get_characters` if you need character IDs.
2. Use `get_nav_snapshot` for overall value.
3. Use `get_character_wallet` for ISK on a character.
4. Use `get_user_market_orders` for open listings.
5. Use `get_industry_jobs` for builds in progress.
6. Use `get_profit_summary` for recent trading results.
